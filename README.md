# nicholashong.dev

My personal site: research projects, a short blog and contact details.

Built with Astro and Tailwind, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```

## Where things live

- `src/features/projects/content.ts`: project pages
- `src/features/blog/content/en/`: blog posts (MDX)
- `src/i18n/ui.ts`: page titles and UI text
- `public/papers/`: PDFs linked from project pages
